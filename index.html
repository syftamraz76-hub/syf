      ☁️ قاعدة البيانات

      كل تعديل تحفظه هنا ينتقل مباشرة لكل من فتح الموقع، ويبقى محفوظاً داخل Firebase حتى لو أغلقت الموقع ورجعت لاحقاً.

      🎨 المظهر العام

      🏷️ شعار الموقع والمشاركة

      ارفع شعارك هنا. سيتم حفظه في Firebase Storage ويظهر عند كل اللاعبين، ويستخدم أيضاً كأيقونة للموقع وبطاقة عند مشاركة الرابط.

      يفضل صورة مربعة PNG أو WebP. سيتم إنشاء صورة مشاركة 1200×630 تلقائياً.

      🖼️ خلفية الموقع

      ارفع صورة خلفية من جهازك، أو الصق رابط صورة مباشر في الخانة. سيتم حفظها بالسحابة وتظهر لكل اللاعبين.

      الخلفية تدعم PNG / JPG / WebP، والأفضل صورة عريضة.

      حماية السحابة: ترك خانة الخلفية فارغة لا يحذف الصورة ولا يغيرها.

      🏠 نصوص الصفحة الرئيسية

      🎬 العرض المشوّق

      ارفع فيديو MP4/WebM أو ضع رابط مباشر للفيديو. زر العرض المشوّق في الصفحة الرئيسية يشغله داخل نافذة فخمة.

      العرض الحالي: لم يتم إضافة فيديو.

      🧭 أزرار الشريط العلوي

      📖 صفحات الموقع

      🔊 صوت الرعب المخصص

      ارفع أي ملف صوت MP3 / WAV / OGG أو ضع رابط مباشر. إذا تركته فارغاً، سيعمل صوت الرعب المدمج الافتراضي.

      الصوت الحالي: الافتراضي المدمج.

      👥 إدارة اللاعبين

      🕯️ تصاريح فتح المستويات

      هنا توافق أو ترفض طلبات اللاعبين. الموافقة تفتح المستوى للاعب، والرفض يبقيه مغلقاً.

      ⚔️ تحديات المستويات

      كل مستوى يسمح بثلاثة تحديات فقط. تستطيع تغيير نوع التحدي: نصي، اختيارات، كاميرا، توقيع، تسجيل صوتي، أو رفع ملف/صورة من الألبوم.

      إضافة تحدي لهذا المستوى

      💞 أسئلة الكبلز

      كل مستوى يحتوي 10 أسئلة كبلز، والإجابة تظهر للاعب كنص فقط بدون اختيارات.

      🧭 تقدم اللاعبين

      هنا تشوف المستويات المكتملة والتصاريح المفتوحة لكل لاعب. تقدر تفتح التالي، أو ترجع لاعب لمستوى محدد بدون تصفير كل تقدمه.

      📥 النتائج والتصحيح

      كل إجابة تحتاج تصحيح من الإدارة. بعد تصحيح كل الأسئلة اضغط اعتماد الاجتياز أو عدم الاجتياز.

      ⛔ إدارة الخسارة

      تحكم هنا في القائمة التي تظهر للاعب عند عدم الاجتياز. المتطلبات تتحدث فوراً وتظهر للاعب عند تسجيل الدخول أو عند تصحيح نتيجته كخسارة.

      📋 الخسارات الحالية

      تقدر تفتح أو تغلق قائمة الخسارة لأي لاعب، وتكتب ملاحظة خاصة تظهر له تحت المتطلبات.

      📜 لوق كل تحركات الموقع

      يسجل دخول اللاعبين والمسؤولين، التنقل بين الشاشات، ضغط الأزرار، تغيير الحقول، رفع الملفات، تسجيل الصوت، التسليم، التصحيح، وإدارة الخسارة. كلمات المرور لا تظهر في اللوق.
